Jev UI demos

Two demos rebuilt from “Jev Is WAY More Powerful Than We Thought” plus one for Score, running on the open-source, Jev-compatible Laya model. Each interaction is a set of typed decisions (Choice / Score / Noul) - no text generation.

🚋

The trolley problem, 100 times

One Choice per trial: pull the lever or leave it alone. Watch 100 decisions get recorded, then try the “1 on main, 5 on side” sanity check.

Creative emoji pile

Type a request like “things you can wear in winter”. Every emoji in the pile is one Noul decision; the ones that stand out fly up under the prompt.
